# Thiruppathi — Frontend Developer Portfolio

A clean, modern, and responsive personal portfolio website built with HTML5, CSS3, and vanilla JavaScript.

🌐 **Live Website**: [https://thirupathimaran-blip.github.io/portfolio-/](https://thirupathimaran-blip.github.io/portfolio-/)

---

## 🚀 Features

- **Responsive Layout**: Adapts smoothly across mobile, tablet, and desktop form factors with custom media queries.
- **Theme Switcher**: Smooth light and dark mode toggling with system preference detection and `localStorage` persistence.
- **Selected Projects**:
  - **This Portfolio** (2026): Hand-crafted resume site with interactive contact form and local persistence.
  - **Weather Dashboard** (2026): Responsive live weather lookup interface.
  - **Task Tracker** (2025): State-driven task management application in React.
  - **Gestosis Platform PRD** (2026): Product requirements and architecture for maternal health monitoring.
- **Working Contact Form**: Built-in client-side validation and local storage persistence for form submissions.
- **Admin Response Viewer**: Protected demo dashboard (`admin` / `admin123`) to review messages sent via the contact form.

---

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5
- **Styling**: Modern CSS3 (CSS Variables, Flexbox, Grid, Glassmorphism, Smooth Scrolling)
- **Scripting**: Vanilla JavaScript (ES6+, no external runtime dependencies)
- **Typography**: Fraunces, IBM Plex Sans, IBM Plex Mono
